# 🎯 Online Quiz System

## 📌 Project Overview

The **Online Quiz System** is a web-based application designed to conduct quizzes efficiently. It allows users to attempt quizzes, view scores, and manage questions dynamically. The system is built to provide a smooth and interactive learning experience.

---

## 🚀 Features

* 👤 User Registration & Login
* 📝 Attempt Quizzes
* ⏱️ Timer-based quiz system
* 📊 Instant Result & Score Display
* 📚 Multiple Courses & Questions
* 🔄 Real-time updates (WebSocket support)
* 🗄️ SQLite Database Integration

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, TypeScript
* **Database:** SQLite (`quiz.db`)
* **Real-time:** WebSockets
* **Tools:** tsx, dotenv

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Pooja-1636/online_quiz.git
cd online-quiz-system
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the project

```bash
npm run dev
```

---

## 🌐 Usage

* Open browser: `http://localhost:3000`
* Register/Login
* Start quiz
* View results instantly

---

## ⚠️ Important Notes

* Ensure ports **3000** and **WebSocket port** are free before running
* If port issue occurs:

```bash
npx kill-port 3000
```
